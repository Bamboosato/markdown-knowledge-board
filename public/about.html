Markdown Knowledge Board

About / アプリについて

Markdown Knowledge Boardは、Markdownでノートを作成・編集・整理できる、ローカル保存を基本とするWebアプリです。基本機能はアカウント接続なしで利用できます。

Markdown Knowledge Board is a local-first web app for writing, editing, and organizing Markdown notes. Its core features work without connecting an account.

Open App / アプリを開く

Features / 主な機能

Markdown編集・プレビュー、タグによる整理、Markdownの取り込み・出力、HTML・PDF出力、ローカルバックアップに対応しています。ノートはブラウザー内に保存されます。

Features include Markdown editing and preview, tags, Markdown import and export, HTML and PDF export, and local backups. Notes are stored in your browser.

Optional cloud connections / 任意のクラウド連携

Google Driveに接続すると、選択したフォルダーへのMarkdown出力と、「MKB Backups」への暗号化バックアップ・復元が利用できます。GitHubに接続すると、暗号化したバックアップを非公開Gistに保存・復元できます。

Connecting Google Drive enables Markdown export to a folder you select and encrypted backup and restore in “MKB Backups”. Connecting GitHub enables encrypted backup and restore using a secret Gist.

Markdown出力は暗号化されません。暗号化バックアップのパスフレーズはご自身で管理してください。紛失した場合、運営者による復旧はできません。

Markdown exports are not encrypted. Keep your encrypted backup passphrase safe; the operator cannot recover a lost passphrase.
