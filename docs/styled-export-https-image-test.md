# HTTPS画像読み込み確認

この画像はHTTPSの外部サーバーにあります。Styled HTML / PDFの出力画面を開いた時点では未解決のため、「Load HTTPS images」ボタンが表示されます。

![Wikimedia Commonsのロゴ](https://upload.wikimedia.org/wikipedia/commons/4/4a/Commons-logo.svg)

「Load HTTPS images」を押すと、画像の取得に成功した場合はプレビューにロゴが表示され、ボタンが消えます。

画像の出典: [Wikimedia Commonsのロゴ](https://commons.wikimedia.org/wiki/File:Commons-logo.svg)
